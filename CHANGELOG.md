# Changelog

All notable changes to this project are documented in this file.

## [@myriosx/cli-kit@0.0.1] - 2026-11-12

Initial release of `@myriosx/cli-kit`.

### Added

- Declarative CLI applications, commands, plugins and authentication with typed arguments and structured JSON input.
- Structured output, typed errors, pagination, pipes and human-readable rendering for business CLIs and AI agents.
- OAuth, bearer token, API key and Basic authentication, with credential providers, token refresh and transactional local storage.
- HTTP request controls, including a default 30-second timeout, caller cancellation and typed failures for HTTP errors.
- Skill discovery, generation and synchronization, the bundled `agent-cli-builder` skill, an installation wizard and update notifications.
- Public ESM entry points at the package root, `/advanced`, `/errs`, `/credentials` and `/skills`, with TypeScript declarations.
- Documentation, Node.js 26+ and Bun 1.4+ support, release metadata validation and packaged-consumer checks.
