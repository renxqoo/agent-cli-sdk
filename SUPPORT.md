# Support

- Usage questions and reproducible bugs: open a GitHub issue with the package version, Node.js version, operating system, command, expected result, and sanitized output.
- Feature proposals: open a feature request describing the user problem before the proposed API.
- Security reports: follow `SECURITY.md`; never post credentials, tokens, or private service URLs publicly.

The project is maintained on a best-effort basis. The latest published version is the default support target.
